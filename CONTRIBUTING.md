# Contributing

Contributions to this decompilation project may include source reconstruction, symbol naming, data-format research, tooling, asset documentation, version-difference analysis, verification, and reproducibility work.

## Rules

- Do not commit retail ROM images, decrypted game images, keys, or redistributable game binaries.
- Prefer small, reviewable commits with a clear purpose.
- Record versions, offsets, hashes, assumptions, and verification methods when relevant.
- Clearly distinguish confirmed findings from hypotheses.
- Keep generated output reproducible from documented source data and tooling whenever practical.

## Pull requests

Explain what was reconstructed or documented, how it was verified, and any known limitations or unresolved questions.
