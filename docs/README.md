# Documentation

This directory is the documentation hub for the decompilation project.

## Planned documentation

- executable and code structure
- data formats and tables
- scripts and event systems
- graphics, audio, maps, and asset formats
- version, language, and revision differences
- symbol maps and naming notes
- extraction, reconstruction, and repacking tools
- verification methods, hashes, and reproducibility notes

## Research policy

Confirmed findings should be separated from hypotheses. Record the relevant game version or revision, offsets or identifiers, verification method, and supporting evidence whenever practical.

## Suggested layout

```text
docs/
├── architecture/
├── formats/
├── research/
├── versions/
└── verification/
```

Additional directories should be added as research becomes concrete rather than as empty placeholders.
